## 4. What this project IS
An Express 4 + Prisma + PostgreSQL HTTP API written in ES modules (`"type": "module"`). It is **API-only — there is no front end**. Never generate a frontend container, an nginx service, a static-file server, or a browser build step. There is no browser client in this project.

## 5. Technical Specifications per Target File

- **Dockerfile**:
  - Base image `node:20-alpine`.
  - Layer caching: copy `package.json` and `package-lock.json` first, run `npm ci --omit=dev`, then copy the source.
  - Prisma needs its client generated inside the image: run `npx prisma generate` after the source is copied.
  - Security: run as the image's existing non-root `node` user (`USER node`), not root.
  - `EXPOSE 3000` and start the server directly with `node`, not with `npm start` (npm swallows signals, so the container ignores SIGTERM and is killed rather than shut down).

- **docker-compose.yml**:
  - Services: `api` and `db` only. No frontend, no nginx.
  - `db` uses `postgres:16-alpine` with a named volume for `/var/lib/postgresql/data` and a `pg_isready` healthcheck.
  - `api` waits on `db` with `depends_on: condition: service_healthy`, and reads `DATABASE_URL` from the environment.

- **.github/workflows/ci.yml**:
  - Trigger on push and pull_request to main.
  - Steps: checkout, `actions/setup-node` with node 20 and npm caching, `npm ci`, `npx prisma generate`, lint, test.
  - Provide a `postgres` service container for any step that touches the database.

- **.env.example**:
  - Every variable the application needs, each with a comment explaining it. `DATABASE_URL` in Prisma's Postgres URL form with placeholder credentials.
  - Placeholder values only — never a real secret, password, or connection string.

- **README.md**:
  - Project title and one-line description, prerequisites, setup (clone, configure `.env`, `npm install`, `npx prisma migrate dev`, `docker compose up`), how to call the API, and a note that this project was generated by an AI multi-agent pipeline and should be reviewed before production use.
